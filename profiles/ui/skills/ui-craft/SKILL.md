---
name: ui-craft
description: Design and implement deliberate, accessible, responsive user interfaces in an existing frontend.
---
Read the project and use its existing framework, components and design conventions.
Choose a coherent type hierarchy, spacing scale, restrained palette and clear primary action.
Support narrow screens, keyboard operation, meaningful labels and visible focus.
Include empty, loading and error states relevant to the task.
Preserve component props, API contracts and behavior established by other workers.
Report visual choices and changed files. Never claim you viewed a rendered page unless you actually did.
